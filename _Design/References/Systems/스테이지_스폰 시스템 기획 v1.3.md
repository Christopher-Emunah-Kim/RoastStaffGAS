# 💡 스테이지 시스템 상세 기획서

## 핵심 역할

> 
> 
> 
> 
> - 스테이지 시스템은 인게임 세션의 전체 흐름을 관리하는 시스템이다.
> - 웨이브 진행, 적 스폰 요청, 보스 트리거, 클리어/실패 판정, 결과 처리까지 인게임에서 발생하는 모든 상태 전환의 중심 역할을 한다.
> 
> ### **핵심 책임**
> 
> - 스테이지 시작·종료 및 게임 시간 제어를 담당한다.
> - 웨이브 구간을 시간 기준으로 관리하고, 구간 전환 시 스포너에게 스폰 파라미터를 전달한다.
> - 스포너에게 스폰할 적의 종류, 수량, 방향 정보를 전달한다. 실제 스폰 실행은 스포너에 위임한다.
> - 현재 생존 중인 적 목록과 누적 처치 수를 관리한다.
> - 보스 트리거 조건을 감시하고 조건 달성 시 보스 스폰을 요청한다.
> - 클리어 조건(생존 시간 달성) 및 실패 조건(플레이어 사망)을 판정한다.
> - 세션 종료 시 처치 수, 생존 시간, 획득 전리품을 집계하여 결과 데이터를 생성한다.
>

### 웨이브 관리 상세 규칙

> 
> 
> 
> 
> - 웨이브는 경과 시간을 기준으로 자동 전환된다. 
> 플레이어가 모든 적을 처치하더라도 시간이 남아있으면 웨이브는 계속 진행된다.
> 
> - **웨이브 구간 전환 규칙**
>     - 스테이지 시작 시 경과 시간 타이머가 동작하기 시작한다.
>     - 경과 시간이 DT_Stage에 정의된 웨이브 구간의 시작 시간에 도달하면 해당 웨이브로 전환한다.
>     - 웨이브 전환 시 새 웨이브의 스폰 파라미터(적 ID 목록, 스폰 간격, 최대 동시 적 수)를 스포너에 전달한다.
>     - 웨이브 전환 시 HUD의 웨이브 표시를 갱신한다.
> 
> - **웨이브 구간 데이터 예시**
>     - 웨이브 구간별 수치는 DT_Stage에서 관리한다. 
>     밸런싱이 필요한 경우 데이터 테이블만 수정하여 반영한다.
> 
> | **웨이브 구간** | **경과 시간** | **스폰 간격** | **최대 동시 적 수** | **특징** |
> | --- | --- | --- | --- | --- |
> | Wave 1 | 00:00 ~ 01:30 | 2.0초 | 30 | 기본 적만 등장 |
> | Wave 2 | 01:30 ~ 03:00 | 1.5초 | 50 | 중형 적 등장 |
> | Wave 3 | 03:00 ~ 05:00 | 1.0초 | 80 | 엘리트 적 등장 |
> | Boss Wave | 05:00 ~ | - | 1 + 30 | 보스 + 잡몹 동시 등장 |
> 

### 적 스폰 요청 상세 규칙

> 
> 
> 
> 
> - 스테이지 시스템은 스포너에게 스폰 파라미터를 전달하는 역할만 담당한다. 
> 실제 적 액터의 생성과 배치는 스포너가 처리한다.
> 
> - **스폰 요청 프로세스**
>     - 스폰 간격 타이머가 만료될 때마다 스포너에게 스폰 요청을 전달한다.
>     - 스폰 요청 시 아래 정보를 함께 전달한다.
>         - 스폰할 적 ID
>         : 현재 웨이브의 SpawnEnemyIDs와 SpawnWeights를 기반으로 가중치 랜덤 선택
>         - 최초 스폰 방향
>         : 현재 플레이어의 위치를 기준으로 화면 외곽 방향을 계산하여 전달
>         - 최대 동시 적 수
>         : 현재 생존 적 수가 최대치 미만인 경우에만 스폰 요청을 전달
>         - 스포너는 전달받은 정보를 기반으로 화면 외곽의 유효한 위치에 적을 스폰한다.
>     - 스폰된 적은 전달받은 초기 방향(플레이어 위치)을 향해 이동을 시작한다. 이후 이동은 AI 컨트롤러가 독립적으로 처리한다.
>     - 현재 생존 적 수는 스테이지 시스템이 관리하는 생존 적 목록의 수량으로 판단한다.
>     - 적이 처치되거나 맵 밖으로 이탈하면 목록에서 제거된다.
> 

### 처치 집계 상세 규칙

> 
> 
> 
> 
> - **적 처치 이벤트 처리 프로세스**
>     - 적이 처치되면 처치 이벤트가 스테이지 시스템에 전달된다.
>     - 누적 처치 수를 1 증가시킨다.
>     - 처치이벤트 수신 시 EnemyID를 레벨업 시스템에 전달. → 레벨업 시스템이 ID로 GDS에 DropEXP 조회하여 경험치 처리.
> 

### 보스 트리거 관리 상세 규칙

> 
> 
> 
> 
> - **보스 등장 조건**
>     - DT_Stage의 BossTriggerTime에 정의된 경과 시간에 도달하면 보스 트리거가 발동된다.
>     - 보스 트리거 발동 시 스포너에게 보스 스폰을 요청한다.
>     - 보스는 화면 외곽 특정 위치에 스폰되며, 일반 웨이브 스폰은 보스 스폰과 동시에 유지된다.
>     
> - **보스 처치 처리**
>     - 보스 처치 시 즉시 클리어로 처리하고 결과프로세스로 진행한다.
>     ([스테이지 결과 처리 상세 규칙](https://www.notion.so/3121ba272aac805c8cdae48020b99c2e?pvs=21) 참조)
> 

### 클리어/실패 판정 상세 규칙

> 
> 
> 
> 
> - **클리어/실패 판정 상세 규칙**
>     - 클리어
>         - 경과 시간이 스테이지 제한 시간에 도달
>         - 게임시간 정지 → 클리어 연출 재생 → 결과처리 프로세스
>     - 실패
>         - 플레이어HP가 0 이하로 감소
>         - 게임시간 정지 → 실패 연출 재생 → 결과 처리 프로세스
>     - 클리어/실패가 동시에 발생하는 경우(마지막 순간 사망 등)  실패를 우선 처리한다.
> 

### 스테이지 결과 처리 상세 규칙

> 
> 
> 
> 
> - **결과 데이터 집계 프로세스**
>     - 클리어 또는 실패 판정이 내려지면 결과 데이터 집계를 시작한다.
>     - 아래 항목을 집계하여 결과 데이터 구조체를 생성한다.
>         - 클리어/실패 여부
>         - 총 생존 시간
>         - 총 처치 수
>         - 처치한 적 종류별 수량
>         - 획득한 전리품 목록 및 수량
>         - 획득한 총 경험치 및 골드
>     - 집계된 결과 데이터를 결과 화면 UI에 전달하여 표시한다.
>     - 결과 데이터를 세이브 시스템에 전달하여 영구 저장을 요청한다.
> 
> - 예외처리
>     - 결과 처리 중 게임 강제 종료
>         - 집계된 데이터까지만 저장하고 미집계 항목은 기본값(0)으로 처리한다.
>     - 스테이지 도중 플레이어가 직접 나가기 선택
>         - 실패 로직과 동일하게 처리한다. 결과 데이터를 집계하고 결과 화면을 표시한다.
>     - 스테이지 보스 처치 시
>         - 즉시 클리어로 처리한다. 보스 처치 추가 보상을 포함하여 집계하고 결과 화면을 표시한다.
>

## **DT_WaveData 스키마**

| SpawnEnemyIDs | ARRAY\<STRING\> | NOT NULL | 스폰 가능한 적 ID 목록. DT_Enemy 참조 |
| SpawnWeights | ARRAY\<FLOAT\> | NOT NULL | SpawnEnemyIDs별 스폰 가중치 (합산 1.0) |

## **런타임 데이터 구조**

- 스테이지 시스템이 세션 중 관리하는 런타임 상태 데이터 목록이다. 
이 데이터는 저장되지 않으며 세션 종료 시 폐기된다.

| **데이터 항목** | **타입** | **설명** |
| --- | --- | --- |
| 현재 스테이지 ID | STRING | 현재 진행 중인 스테이지 ID |
| 경과 시간 | FLOAT | 스테이지 시작 후 경과한 시간 (초). 매 프레임 갱신 |
| 현재 웨이브 인덱스 | INT | 현재 활성화된 웨이브 구간 번호 |
| 생존 적 목록 | ARRAY | 현재 맵에 생존 중인 적 액터 참조 목록 |
| 누적 처치 수 | INT | 세션 시작 이후 처치한 총 적 수 |
| 보스 스폰 여부 | BOOL | 보스가 이미 스폰되었는지 여부. 중복 스폰 방지용 |
| 스테이지 결과 상태 | ENUM | 진행 중 / 클리어 / 실패 중 하나 |

## **결과 화면 UI**

### **화면 구성**

| **영역** | **위치** | **표시 내용** |
| --- | --- | --- |
| 상단 | 결과 화면 상단 | 스테이지명 + 클리어/실패 여부 + 총 생존 시간 |
| 중앙 좌 | 결과 화면 중앙 왼쪽 | 총 처치 수, 처치한 적 종류별 수량, 총 피해량 |
| 중앙 우 | 결과 화면 중앙 오른쪽 | 최종 보유 무기 목록 (슬롯 0~2) |
| 하단 | 결과 화면 하단 | 획득 골드 + 획득 경험치 + 메인 메뉴로 버튼 |

### **결과 화면 전환 규칙**

- 클리어 판정 시 클리어 연출(이펙트 + BGM 전환)을 재생한 후 결과 화면으로 전환한다.
- 실패 판정 시 실패 연출(화면 페이드 아웃)을 재생한 후 결과 화면으로 전환한다.
- 결과 화면에서 메인 메뉴로 버튼을 누르면 세이브 처리 완료 후 메인 메뉴로 전환한다.
