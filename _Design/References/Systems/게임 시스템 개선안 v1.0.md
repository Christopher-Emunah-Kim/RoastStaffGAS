## 1. 게임 정체성

### 핵심 정의

> **캐릭터 빌드 서바이버**
> 로비에서 캐릭터를 육성하고, 인게임에서 무기·패시브 시너지를 구성하며, 스킬 타이밍으로 위기를 돌파한다.

### 기존 Vampire Survivors 대비 차별점

| 요소 | VS | 이 게임 |
|------|----|--------|
| 무기 발사 | 자동 | 자동 (동일) |
| 캐릭터 차이 | 스탯·시작 무기 | 고유 스킬 2개 (플레이 스타일 변화) |
| 인게임 능동 개입 | 없음 | 스킬 Q/E 타이밍 발동 |
| 런 전 빌드업 | 없음 | 로비 스탯트리 + 시작무기 선택 |
| 메타 성장 | 캐릭터 해금 | 캐릭터 해금 + 공통 스탯트리 영구 성장 |

### 재미 레이어

| 레이어 | 내용 | 핵심 감정 |
|--------|------|----------|
| 메타(로비) | 스탯트리 노드 해금, 캐릭터/무기 구매 | 내 캐릭터가 강해지는 성장감 |
| 런 내 빌드 | 레벨업마다 스탯/패시브/무기 선택 | 매 런 다른 조합 발견 |
| 인게임 플레이 | 무기 자동발사 + 스킬 Q/E 타이밍 | 스킬 쿨타임 관리 긴장감 |
| 장기 목표 | 진화 시스템 (무기+패시브 조합) | 조합 목표를 향한 빌드 방향성 |

## 2. 아웃게임 플로우

### 전체 플로우

```
[로비]
  └─ [캐릭터 선택] ← 해금된 캐릭터 목록 표시 (잠긴 캐릭터는 UnlockCost 표시)
        └─ [캐릭터 커스터마이즈]
              ├─ 시작 무기 선택  ← 해금된 무기 공통 풀에서 1개 선택
              └─ 메타 업그레이드 ← 스탯 트리 노드 해금 (재화 소비)
        └─ [스테이지 선택]
              └─ 스테이지 클릭
                    └─ [스테이지 정보창] ← 출현 에너미 목록 + 클리어 보상(골드) 표시
                          └─ [게임 입장]
```

### 캐릭터 선택 규칙
- 로비에 캐릭터 선택 UI 통합 (기존 인게임 진입 전 선택 방식 폐기)
- 해금 조건: DT_Character.IsUnlocked = true
- 잠긴 캐릭터 클릭 시: 해금 비용(UnlockCost) 및 골드 부족 여부 표시

### 시작 무기 선택 규칙
- 공통 풀: 전 캐릭터가 동일한 무기 풀 공유
- 해금 조건: DT_Weapon.IsUnlocked = true
- 선택한 무기가 게임 시작 시 슬롯 1에 장착

### 스테이지 정보창 표시 항목
- 스테이지 이름
- 출현 에너미 목록 (DT_Stage.SpawnEnemyIDs 기반, 에너미 아이콘 + 이름)
- 보스 에너미 (DT_Stage.BossEnemyID, 있을 경우)
- 클리어 보상: 골드 (DT_Stage.RewardGold)

## 3. 인게임 시스템

### 3-1. 무기 시스템 (변경)

#### 발사 방식 변경
- **변경 전**: 수동발사 (마우스 클릭 트리거, 액티브 모드)
- **변경 후**: 자동발사 (조건 충족 시 자동 트리거)

#### 자동발사 규칙
- 타겟팅 기준: **최근접 적** (범위 내 없으면 대기)
- 각 무기는 **독립적인 쿨타임**으로 개별 작동
- 두 슬롯의 무기가 동시에 자동발사 (번갈아 발사 아님)
- 쿨타임, 공격력, 발사 수, 공격 방식은 DT_Weapon에서 관리

#### 무기 슬롯 구성
- **슬롯 1**: 시작 무기 (로비에서 선택)
- **슬롯 2**: 빈 슬롯으로 시작 → 레벨업 선택지로 채움
- 두 슬롯 모두 자동발사로 작동

#### EvolutionTag (진화 시스템 대비)
- 기존 DT_Weapon.BaseType 컬럼을 **EvolutionTag**로 rename
- 이후 진화 시스템에서 "무기 EvolutionTag + 패시브 EvolutionTag → 조합 조회"에 사용
- 지금은 필드만 유지, 로직 미구현

---

### 3-2. 캐릭터 고유 스킬 시스템 (신규)

#### 개요
- 모든 캐릭터는 **고유한 스킬 2개**를 보유
- 캐릭터마다 완전히 다른 스킬 (스탯 차이가 아닌 플레이 스타일 차이)
- 스킬은 캐릭터가 바뀌면 함께 바뀜 (런마다 동일, 뽑기 아님)

#### 키 바인딩
- 스킬 1: **Q**
- 스킬 2: **E**
- UI에 Q/E 단축키 표기 (스킬 아이콘 하단)

#### 쿨타임 범위
- 스킬 1: **8~12초** (상대적으로 자주 사용)
- 스킬 2: **20~30초** (궁극기급, 상황 전환용)
- 실제 수치는 DT_Skill에서 캐릭터별로 정의

#### 스킬 발동 타입 ENUM: ESkillActivationType

| 값 | 발동 방식 | 설명 |
|----|----------|------|
| `InstantAoE` | 즉발 범위기 | Q/E 누르면 캐릭터 주변 즉시 발동 |
| `SpawnPreview` | 위치 지정형 | Q/E 누르면 프리뷰 FX 표시 → 좌클릭으로 위치 확정 후 발동 |
| `SelfBuff` | 자가 버프 | Q/E 누르면 캐릭터 자신에게 즉시 효과 적용 |

#### SpawnPreview 상세 규칙
- Q/E 입력 → 마우스 위치 기반 범위 프리뷰 FX 표시
- 좌클릭 → 해당 위치/방향으로 스킬 발동, 쿨타임 시작
- **우클릭** → 취소 (쿨타임 소모 없음)
- 미리보기 상태에서 **이동 가능** (이동 제약 없음)

#### 스킬 레벨 시스템
- 최대 **3레벨**
- 레벨업 방법: 스탯 트리의 **마일스톤 BIG 노드** 해금 시 자동 상승 (별도 재화 소비 없음)
  - 스킬 Lv1 → Lv2: 스탯 트리 **3번째 BIG 노드** 해금 시
  - 스킬 Lv2 → Lv3: 스탯 트리 **6번째 BIG 노드** 해금 시
- 레벨별 변화: 수치 증가 (DT_Skill 레벨 데이터) + FX 시각적 변화
- 캐릭터 스킬 레벨은 캐릭터별로 독립 저장

### 3-3. 레벨업 선택지 시스템 (변경)

#### 기본 규칙
- 매 레벨업마다 **3장** 제시
- 정적 카드 + 동적 카드 혼합 풀에서 추출

#### 카드 풀 구성

**정적 카드 (DT_LevelUpCard에 사전 정의)**

| 카드 타입 | 등장 조건 | 내용 |
|----------|----------|------|
| 스탯 업그레이드 | 항상 | ATK%, DEF%, MaxHP%, MoveSpeed%, AttackSpeed%, CritRate+, CritDamage+ |
| 패시브 스킬 추가 | 패시브 슬롯 < 4 | DT_Passive에서 랜덤 선택 |

**동적 카드 (런타임 생성)**

| 카드 타입 | 등장 조건 | 내용 |
|----------|----------|------|
| 장착 무기 업그레이드 | 항상 | 현재 장착한 무기 기준으로만 생성. DT_Weapon 업그레이드 경로 참조 |
| 새 무기 획득 | **항상 등장** | 슬롯 여유 있으면 슬롯 2에 장착, 꽉 차면 Replace UI 트리거 |

> **중요**: 무기 업그레이드 카드는 현재 장착한 무기에 대해서만 생성된다.
> 장착하지 않은 무기의 업그레이드 카드는 등장하지 않는다.

#### 최소 보장 규칙
- 3장 중 **무기 관련 카드 최소 1장** 보장 (업그레이드 or 새 무기)
- 패시브 슬롯이 꽉 찬 경우: 무기 1장 + 스탯 2장
- 완전 랜덤 배치 금지

#### 무기 슬롯 꽉 찬 상태에서 새 무기 획득 선택 시
1. 레벨업 UI 닫기
2. 기존 무기 Replace UI 표시 (어느 슬롯에 갈아끼울지 선택)
3. 선택한 슬롯의 무기를 새 무기로 교체

#### 패시브 슬롯 포화 처리
- 패시브 슬롯 4개 모두 채워지면 패시브 카드 풀 **완전 잠금**
- 이후 레벨업에서 패시브 카드 미등장
- 패시브는 한 번 배치 후 **변경 불가** (영구 고정)
- 오직 무기 슬롯만 교체 가능

---

### 3-4. 패시브 시스템 (신규)

#### 개요
- 레벨업 선택지에서 획득, 최대 **4슬롯**
- 획득 후 영구 고정 (교체 불가)
- GE(GameplayEffect) 기반으로 적용

#### EvolutionTag 필드
- 각 패시브는 `EvolutionTag` 보유
- 이후 진화 시스템에서 "무기 EvolutionTag == 패시브 EvolutionTag" 조합 시 진화 발동
- 현재는 필드만 존재, 조합 로직 미구현

### 3-5. 데미지 공식 (신규 적용)

#### GAS ExecCalc으로 구현

**플레이어 → 에너미**
```
FinalDamage = WeaponBaseDamage × (1 + ATK / 100) × CritMultiplier

CritMultiplier:
  - random() < CriticalRate  → CriticalDamage 배율 적용
  - 그 외                    → 1.0
```
- ATK = PlayerAttributeSet.ATK (GAS 어트리뷰트)
- WeaponBaseDamage = 장착 무기의 기본 데미지 (DT_Weapon)
- 에너미는 DEF 없음 — 에너미 난이도는 HP/속도/수량으로 조절

**에너미 → 플레이어**
```
FinalDamage = max(1, EnemyAttackDamage - PlayerDEF)
```
- 최소 데미지 1 보장
- PlayerDEF = PlayerAttributeSet.DEF (GAS 어트리뷰트)

> 스탯 추가 시 공식 확장. 현재 ATK/DEF 외 신규 스탯은 이 문서에 추가 기재.

## 4. 메타 시스템

### 4-1. 재화 (골드)

#### 규칙
- **단일 재화** (골드 하나만 존재)
- **획득**: 스테이지 결과 화면에서만 지급 (적 처치 시 즉시 드랍 없음)
- 반복 플레이 유도 구조

#### 소비처

| 항목 | 데이터 출처 | 비고 |
|------|-----------|------|
| 캐릭터 해금 | DT_Character.UnlockCost | 기존 필드 활용 |
| 시작 무기 해금 | DT_Weapon.UnlockCost | 신규 필드 추가 |
| 스탯 트리 노드 해금 | DT_StatTree.NodeCost | 신규 테이블 |

---

### 4-2. 공통 스탯 트리

#### 개요
- 모든 캐릭터가 **공유**하는 단일 트리
- 재화(골드)로 노드 해금
- 노드 수 상한 있음 (무한 업그레이드 불가)

#### 트리 구조

```
패턴: [BIG] → [SMALL_A][SMALL_B] → [SMALL_C][SMALL_D] → [BIG] → ...
```

**노드 타입**

| 타입 | 설명 | 해금 조건 |
|------|------|----------|
| BIG 노드 | 큰 스탯 상승 / 스킬 마일스톤 | 앞의 SMALL 쌍 2개(총 4개) 모두 해금 후 활성화 |
| SMALL 노드 | 작은 스탯 상승 | 이전 BIG 노드 해금 후 어느 순서든 해금 가능 |

**구조 상세**
- BIG 노드 사이에 SMALL 노드 **2쌍(총 4개)** 배치
- SMALL 1쌍(2개)은 병렬 — 순서 무관 개별 해금 가능
- 두 번째 SMALL 쌍은 첫 번째 SMALL 쌍 2개 모두 해금 후 활성화
- BIG 노드는 두 번째 SMALL 쌍 2개 모두 해금 후 활성화

**구조 예시**
```
[BIG: ATK+10]
  → [SMALL: DEF+3] [SMALL: Speed+2]       ← 1번째 쌍 (둘 다 해금 가능)
    → [SMALL: CritRate+3] [SMALL: HP+3]   ← 2번째 쌍 (1번째 쌍 완료 후 활성화)
      → [BIG: CritDmg+20]                 ← 3번째 BIG (2번째 쌍 완료 후 활성화)
        → ...
```

#### 스킬 레벨 마일스톤 BIG 노드

| BIG 노드 위치 | 효과 |
|-------------|------|
| 3번째 BIG 노드 | 캐릭터 스킬 Lv1 → **Lv2** 자동 상승 |
| 6번째 BIG 노드 | 캐릭터 스킬 Lv2 → **Lv3** 자동 상승 |

#### 스탯 항목
- ATK, DEF, MaxHP, MoveSpeed, AttackSpeed, CriticalRate, CriticalDamage
- (CastingSpeed 제외 — 스킬 쿨타임은 스킬트리 마일스톤으로 관리)

## 5. 데이터 테이블 변경 사항

### 5-1. 기존 테이블 수정

#### DT_Weapon
```
[변경] BaseType (STRING) → EvolutionTag (STRING)
       이유: 진화 시스템 대비 명칭 정규화. 역할 동일.

[추가] IsUnlocked (BOOL, Default: False) — 시작 무기 해금 여부
[추가] UnlockCost (INT) — 해금 필요 골드
```

#### DT_Passive
```
[추가] EvolutionTag (STRING, Nullable) — 진화 조합 태그 (현재 미사용, 필드만 추가)
```

### 5-2. 신규 테이블

#### DT_Skill (캐릭터 고유 스킬)

| 컬럼명 | 타입 | 제약 | 설명 |
|--------|------|------|------|
| SkillID | STRING | PK, NOT NULL | 스킬 고유 ID |
| OwnerCharacterID | STRING | FK, NOT NULL | DT_Character 참조. 이 스킬을 보유한 캐릭터 |
| SkillSlot | INT | NOT NULL | 1 또는 2 (Q 또는 E) |
| ActivationType | ENUM | NOT NULL | InstantAoE / SpawnPreview / SelfBuff |
| Cooldown | FLOAT | NOT NULL | 쿨타임 (초). 스킬1: 8~12, 스킬2: 20~30 범위 |
| GAClass | STRING | NOT NULL | 발동할 GameplayAbility 클래스 경로 |
| PreviewFXClass | STRING | Nullable | SpawnPreview 타입 전용 프리뷰 FX 클래스 |
| LevelData | ARRAY\<FSkillLevelData\> | NOT NULL | 레벨별 수치+FX 데이터 (3개 원소: Lv1/Lv2/Lv3) |

**FSkillLevelData 구조체**

| 필드 | 타입 | 설명 |
|------|------|------|
| Level | INT | 스킬 레벨 (1/2/3) |
| DamageMultiplier | FLOAT | 데미지 배율 |
| EffectRadius | FLOAT | 효과 반경 (해당 시) |
| Duration | FLOAT | 지속 시간 (SelfBuff 해당 시) |
| FXClass | STRING | 해당 레벨의 발동 FX 클래스 |

---

#### DT_StatTree (스탯 트리 노드)

| 컬럼명 | 타입 | 제약 | 설명 |
|--------|------|------|------|
| NodeID | STRING | PK, NOT NULL | 노드 고유 ID |
| NodeType | ENUM | NOT NULL | BIG / SMALL |
| StatType | ENUM | NOT NULL | ATK / DEF / MaxHP / MoveSpeed / AttackSpeed / CriticalRate / CriticalDamage / SkillLevelUp |

## 6. 구현 단계 계획

### PHASE 1 — 인게임 루프 완성 (최우선)
1. 무기 자동발사 전환 (수동 액티브 모드 제거)
2. 캐릭터 고유 스킬 시스템 (GA + 쿨타임 + Q/E 입력 + SpawnPreview)
3. 데미지 공식 ExecCalc 적용 (ATK/DEF 실제 계산 반영)
4. 레벨업 선택지 확장 (정적+동적 카드 풀, 최소 보장 규칙)
5. 패시브 슬롯 시스템 (최대 4, 잠금 처리)

### PHASE 2 — 아웃게임 플로우 재조립
1. 로비 캐릭터 선택 UI 통합
2. 캐릭터 커스터마이즈 UI (시작무기 선택 + 스탯트리)
3. 스테이지 진입 전 정보창 (에너미 미리보기 + 보상)

### PHASE 3 — 메타 연결
1. 재화(골드) 시스템 (SGS 저장 + 결과 화면 지급)
2. 캐릭터 해금 연결
3. 시작 무기 해금 연결
4. 스탯 트리 구현 (DT_StatTree + 노드 해금 UI)
5. 스킬 레벨 마일스톤 연결

### PHASE 4 — 진화 시스템 (별도 세션, 향후)
- 무기 EvolutionTag + 패시브 EvolutionTag 조합 조회
- 진화 무기 DT 및 GA 구현
- 진화 연출
