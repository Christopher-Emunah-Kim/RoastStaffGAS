# 💡 인트로/트랜지션 시스템 상세 기획서

## 핵심 역할

>
>
>
>
> - 인트로/트랜지션 시스템은 게임의 **최초 진입 흐름**과 **레벨 간 전환 처리**를 담당하는 시스템이다.
> - INTRO 레벨: 게임 최초 실행 시 인트로 영상/배경 → 타이틀 화면 흐름 처리
> - TRANSITION 레벨: 모든 레벨 전환 시 중간 경유지. 다음 레벨 에셋을 비동기 프리로드하고 완료 후 진입.
>
> **핵심 책임**
>
> - INTRO: 배경/인트로/타이틀 위젯 순차 표시, 게임 시작 버튼으로 OUTGAME 레벨 전환
> - TRANSITION: 다음 레벨 에셋 비동기 프리로드, FakeProgress 피드백, 완료 후 목적지 레벨 이동
> - ARSGameInstance: OpenNextLevelByName() / OpenNextLevelLatent() 레벨 전환 규칙 관리
>

---

## 💡 ELevelName 및 MapSettings 정의

```cpp
// ELevelName 열거형
enum class ELevelName : uint8
{
    INTRO,
    TRANSITION,
    OUTGAME,
    STAGE,   // 인게임 스테이지 레벨
};

// ARSGameInstance::MapSettings (DeveloperSettings 또는 GI UPROPERTY)
TMap<ELevelName, FSoftObjectPath> LevelMap;
```

| ELevelName | 실제 레벨 경로 | 설명 |
| --- | --- | --- |
| INTRO | /Game/Levels/L_Intro | 게임 최초 실행 레벨 |
| TRANSITION | /Game/Levels/L_Transition | 레벨 전환 중간 레벨 |
| OUTGAME | /Game/Levels/L_OutGame | 아웃게임 (로비/선택 화면) |
| STAGE | /Game/Levels/L_Stage | 인게임 스테이지 레벨 |

## 💡 ARSGameInstance 레벨 전환 규칙

>
>
>
>
> **OpenNextLevelByName(ELevelName NextLevel):**
> - 레벨 전환의 공식 진입점. 모든 레벨 전환은 이 함수를 거쳐야 한다.
>
> ```
> OpenNextLevelByName(NextLevel):
>   1. SetNextLevelName(NextLevel)
>   2. UMS::ResetAllUIStates()     ← 현재 레벨의 모든 UI 초기화
>   3. UMS::ClearUIHistory()
>   4. SetTimer(0.1s) → OpenLevel("TRANSITION")
> ```
>
> **OpenNextLevelLatent() — TRANSITION 레벨 내부에서만 호출:**
>
> ```
> OpenNextLevelLatent():
>   1. LevelMap[NextLevelName] 경로 조회
>   2. OpenLevel(path)
> ```
>
> - 0.1s 딜레이는 현재 프레임의 UI 정리가 완료된 후 레벨 전환이 시작되도록 보장하기 위함이다.
>

## 💡 INTRO 레벨

### RSIntroGameMode

>
>
>
>
> - BeginPlay 시 RSIntroPlayerController를 취득하고 `OpenFirstWidget()`을 호출한다.
>

### RSIntroPlayerController

>
>
>
>
> - **입력 모드**: SetInputMode(FInputModeUIOnly) + SetShowMouseCursor(true)
>
> **위젯 표시 흐름:**
>
> ```
> OpenFirstWidget():
>   UMS::OpenUIByID(EUIID::BACKGROUND)   ← PERSISTENT 배경
>   UMS::SwitchPageUI(EUIID::INTRO)      ← 인트로 화면 (영상/이미지)
>   → 인트로 완료 (타이머 or 스킵 버튼) → OpenTitleScreen()
>
> OpenTitleScreen():
>   UMS::SwitchPageUI(EUIID::TITLE)      ← 타이틀 화면
> ```
>
> **버튼 핸들러:**
>
> | 핸들러 | 트리거 | 처리 |
> | --- | --- | --- |
> | `OnStartGameClicked()` | 타이틀 화면의 "게임 시작" 버튼 | GI::OpenNextLevelByName(ELevelName::OUTGAME) |
> | `OnExitClicked()` | 타이틀 화면의 "종료" 버튼 | UMS::OpenUIByID(EUIID::EXIT) |
>

## 💡 TRANSITION 레벨

### RSTransitionGameMode

>
>
>
>
> - BeginPlay 시 RSTransitionPlayerController를 취득하고 로딩 프로세스를 시작한다.
>
> **프리로드 흐름:**
>
> ```
> BeginPlay():
>   1. UMS::OpenUIByID(EUIID::LOADING)       ← 로딩 UI 표시
>   2. 다음 레벨 에셋 비동기 프리로드 요청
>   3. 완료 → GI::OpenNextLevelLatent()      ← FinishLoading 없이 즉시 전환
>
> [새 스테이지 레벨 진입 후]
>   스테이지 게임모드가 오브젝트 풀 PreWarm을 시작
>   매 틱마다 실제 PreWarm 진행률을 LoadingWidget에 반영
>   PreWarm 완료 → LoadingWidget::FinishLoading() 호출 → 플레이어 입력 허용
> ```
>
> - LOADING 위젯은 UMS(GameInstanceSubsystem)가 캐시하여 레벨 전환 후에도 생존한다.
> - FakeProgress 방식을 제거하고 PoolingSubsystem이 제공하는 실제 PreWarm 진행률로 대체한다.
> - FinishLoading() 호출 주체: 스테이지 게임모드 (PreWarm 완료 시). 아웃게임 전환 시에는 레벨 진입 즉시 호출.
>

### RSTransitionPlayerController

>
>
>
>
> - **입력 모드**: SetInputMode(FInputModeUIOnly). 트랜지션 중 사용자 입력 차단.
> - 로딩 UI의 진행률 업데이트는 스테이지 게임모드가 담당한다. TRANSITION PlayerController는 입력 차단만 담당.
>

## 💡 예외처리

| 상황 | 처리 |
| --- | --- |
| OpenNextLevelLatent() 호출 시 NextLevelName이 NONE인 경우 | 크래시. SetNextLevelName 없이 전환 시도는 허용하지 않는다. |
| 프리로드 대상 에셋이 없는 경우 | 즉시 GI::OpenNextLevelLatent() 호출. 로드할 에셋 없으면 바로 전환. |
| AssetManager 로드 실패 시 | 경고 로그 출력 후 OnLevelPreloadCompleted() 강제 호출. 에셋 없어도 레벨 진입은 허용. |
| TRANSITION 레벨에서 목적지 레벨 경로가 LevelMap에 없는 경우 | 크래시. 잘못된 ELevelName 전달은 설계 오류. |
