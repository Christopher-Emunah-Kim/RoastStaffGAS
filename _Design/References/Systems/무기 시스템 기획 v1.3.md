### 초기 무기 장착 상세 규칙

>
>
>
>
> - 인게임 진입 시 RSGameMode::BeginPlay()에서 InitDefaultWeapon()을 호출하여 기본 무기를 자동 장착한다.
> - `StartingWeaponIDs(배열)` 방식을 사용하지 않는다. 이 프로젝트는 단일 캐릭터 선택 구조이므로 기본 무기는 캐릭터당 1개(DefaultWeaponID)만 정의된다.
>
> - **초기 무기 장착 흐름:**
>     ```
>     RSGameMode::BeginPlay() → InitDefaultWeapon()
>       → RuntimeDataSubsystem::GetSelectedCharacterID()
>       → GameDataSubsystem::GetCharacterStaticData(CharID).DefaultWeaponID
>       → EquipmentComponent 첫 슬롯(인덱스 0) 장착
>     ```
>
> - DefaultWeaponID는 `FCharacterStaticData.DefaultWeaponID` (FName) 필드에서 조회한다.
>     - 참조: 게임데이터 시스템 기획서 → FCharacterStaticData 스키마
>
> - **예외처리:**
>     - DefaultWeaponID가 NAME_None인 경우
>         - 경고 로그 출력 후 기본 무기 없이 진행 (슬롯 0 비어있는 상태)
>     - GetCharacterStaticData 조회 실패 시
>         - 크래시. 유효하지 않은 캐릭터 ID로 인게임 진입은 허용하지 않는다.
>

### 무기 장착 상세 규칙

>
>
>
>
> - 레벨업 선택 UI를 통해 무기를 획득 시, 우선순위에 따라 무기를 처리 후 슬롯에 장착
> - 무기 간의 조합이 가능하여 진화가 가능한 경우를 체크하는 것을 조합 체크라 한다.
> - 무기 간의 베이스타입이 동일하여 강화가 가능한 경우를 체크하는 것을 강화 체크라 한다.
> - 장착할 수 있는 무기슬롯은 최대 3개.
> - 우선순위는 진화체크 >강화체크 > 슬롯 가용여부
>
> - **레벨업 선택 UI 프로세스**
>     - 레벨업 선택 UI가 표시될때 게임을 일시정지한다.
>     - 무기테이블의 LV1 무기 ID를 랜덤으로 3개 선택하고, 해당 ID 무기의 정보들을 레벨업 선택 UI에 표시한다.(아이콘, 이름, 레벨, 설명 등)
>     - 플레이어가 교체UI의 무기 중 하나를 선택할 시, 해당 슬롯의 테두리에 하이라이트 표시와 체크표시✅를 추가한다.
>         - 해당 무기 선택 시 강화/진화/교체에 따라 상태 미리보기를 표시한다.
>     - 플레이어가 확인 버튼을 누르면, 장착 프로세스를 진행한다.
>
> - **장착 프로세스**
>     - 새로 선택된 랜덤 무기 ID를 현재 보유무기와 함께 조합 테이블에서 조합 가능 여부 탐색한다.
>     무기 진화가 가능한 경우 진화 무기 프로세스 진행(무기 진화 상세 규칙 참조)
>     - 조합 체크에 해당하지 않은 경우 현재 보유무기와 동일한 베이스 타입이고, 최대 강화상태(해당 무기레벨 < 3)인지 확인한다.
>     동일 타입이고, 최대 강화상태가 아닌 경우 무기 강화 프로세스 진행(무기 강화 상세 규칙 참조)
>     - 위 과정을 거쳐 최종 장착무기 결정
>     - 장착무기가 장착될 슬롯을 탐색한다. 비어있는 슬롯이 있을경우 빠른 인덱스의 슬롯부터 장착한다. 비어 있는 슬롯이 없을 경우 장비 교체 UI를 표시한다. (무기 교체-해제 상세 규칙 참조)
>     - 최종적으로 슬롯에 장착된 무기의 인스턴스 데이터를 생성하고, 무기 테이블과 스킬테이블을 참조하여 무기가 사용하는 스킬(Game Ability)을 탐색한다.
>     무기 장착흐름은 GA를 ASC에 등록하는 것까지만 담당한다. 스킬 GA 발동 시 GA 스스로 관련 테이블을 조회하여 스킬 오브젝트를 스폰한다.
>     - 캐릭터에 GA를 부여하고, 무기 오브젝트를 스폰한다.
>     - 0번 슬롯 무기의 경우 캐릭터의 오른손에 장착한다. 1-2번 슬롯 무기의 경우 캐릭터 주변을 공전하도록 한다.
>     필요한 경우, 0번 슬롯 무기의 베이스 타입에 따라 무기를 사용하는 애니메이션을 조절한다.
>
> - **예외처리**
>     - 잘못된 무기 ID인경우
>         - 로그 출력 후 크래쉬
>     - GA클래스 로드 실패 시
>         - 로그 출력 후 해당 슬롯 비활성화
>     - 슬롯이 모두 차있는 경우
>         - 교체 UI 강제 표시(스킵 불가)
>     - 무기 오브젝트 스폰 실패 시
>         - 로그 출력 후 기본 무기 메시 스폰 재시도
>

### 무기 진화 상세 규칙

>
>
>
>
> - 진화는 두개의 베이스타입 무기를 조합하여 상위 무기를 생성하는 시스템이다.
> - 장착할 무기가 현재 장착된 무기와 함께 조합테이블에 정의된 조합이 있고, 진화 조건을 만족하는 경우 진화 프로세스를 진행한다.
>     - 현재 장착된 무기의 레벨이 조합 테이블에 정의된 요구 레벨 이상인 경우 진화 조건이 만족되었다고 한다.
> - 현재 장착된 무기가 요구 레벨을 만족하지 않거나, 조합테이블에 정의된 조합이 없는 경우, 진화가 진행되지 않는다.
>     - 진화를 위한 조합체크는 무기 장착 프로세스에서 최우선순위로 실행된다.(진화 > 강화 > 슬롯체크)
>
> - **진화 프로세스**
>     - 신규 무기의 베이스타입과 현재 장착한 무기들의 베이스타입을 비교하여 조합테이블에서 유효 조합이 있는지 체크한다.
>         - 두 무기의 레벨이 요구레벨 이상인지 체크한다.
>     - 조합 조건을 만족하는 경우, 재료 무기 중 현재 장착된 무기의 슬롯을 해제하고, 부여된 GA와 존재하던 오브젝트를 제거한다.
>     - 진화 무기를 최종 장착 무기로 결정하고, 무기 장착을 진행한다. (무기 장착 상세 규칙 참조)
> - 진화 무기 특징
>     - 진화무기는 일반 무기와 아래와 같은 차이를 둔다.
>
>
>         | 특성 | 일반 무기 | 진화 무기 |
>         | --- | --- | --- |
>         | 강화가능여부 | O(최대 3레벨) | X(단일 레벨) |
>         | 성능 | 중간 | 일반무기 LV3보다 강력 |
>         | 희소성 | 일반 | 희귀 |
>
> - **예외처리**
>     - 진화 무기 ID가 유효하지않은 경우
>         - 로그 출력 후 크래시
>     - 진화 중 게임이 종료된 경우
>         - 데이터 시스템에 진화 트랜잭션 상태 저장
>         - 재접속 시 진화 완료된 상태로 유저 UI에 표출
>     - 진화 무기 GA 로드 실패 시
>         - 로그 출력 후 크래시
>     - 기존 장착된 진화무기가 존재한 상태로 새로 조건이 충족된 조합결과가 동일 무기인 경우
>         - 정상 처리 - 진화무기 여러개 보유가능
>     - 슬롯이 모두 존재하는 상태에서 강화를 통해 요구레벨이 달성된 경우
>         - 진화가 최우선 순위이므로 진화 강제 실행 → 진화 UI 표시
>         - 재료 무기 2개를 제거하여 슬롯 2개 확보
>         - 진화 무기를 빈 슬롯 중 빠른 인덱스에 배치
>

### 무기 강화 상세 규칙

>
>
>
>
> - 강화는 동일 베이스 타입의 무기가 존재할경우 강화 무기를 생성하는 시스템이다.
> - 장착할 무기가 현재 장착된 무기와 동일 베이스타입이고, 현재 장착된 무기의 강화 레벨이 최대 강화상태 이하(해당 무기레벨 < 3)인 경우 강화 프로세스를 진행한다.
> - 현재 장착된 무기가 이미 최대 강화레벨(무기레벨 ==3)이거나 조합을 통한 진화가 성립하는 경우, 강화가 진행되지 않는다.
>     - 무기 조합을 통한 진화가 무기 강화보다 우선하여 적용된다. (우선순위 : 진화> 강화)
>
> - **강화 프로세스**
>     - 획득한 무기가 강화대상인지 확인한다.(동일 베이스타입, 최대 강화상태 아님)
>     - 강화대상인 경우 다음단계 무기 ID를 무기 테이블에서 조회한다.
>     - 강화 대상이 된 현재 장착 무기의 슬롯을 해제하고, 부여된 GA와 존재하는 오브젝트를 제거한다.
>     - 조회한 다음단계 무기를 최종 장착무기로 결정하고, 무기 장착을 진행한다.
>     (무기 장착 상세 규칙 참조)
> - 강화 시 변화
>     - 투사체수, 범위, 데미지, 특수효과, 외형, 이펙트 등의 변화가 발생한다.
>     - 1단계에서 3단계에 따른 변화가 유저에게 인지되도록 한다.
>
> - **예외처리**
>     - 다음 단계 무기 ID가 유효하지않은 경우
>         - 로그 출력 후 크래시
>     - 강화 중 게임이 종료된 경우
>         - 데이터 시스템에 강화 트랜잭션상태를 저장
>         - 재접속시 강화 완료된 상태로 유저 UI에 표출
>     - 강화 무기 GA 로드 실패 시
>         - 로그 출력 후 크래시
>     - 최대강화무기가 존재하는데 동일 베이스타입의 새 무기도 최대강화상태에 도달한 경우(Lv3, Lv2→3)
>         - 신규 장착으로 처리
>

### 무기 교체-해제 상세 규칙

>
>
>
>
> - 교체 UI 표시 조건
>     - 슬롯이 모두 찬 상태에서 신규 무기 획득 시
>     - 진화/강화 조건이 모두 성립하지 않을 때
>
> - **교체 UI 프로세스**
>     - 교체 UI가 표시될떄 게임이 일시정지 상태가 된다.
>     - 플레이어가 교체UI의 무기 중 하나를 선택할 시, 해당 슬롯의 테두리에 하이라이트 표시와 체크표시✅를 추가한다.
>         - 해당 무기 선택에 따른 상태 미리보기(교체 대상이 된 슬롯에 해당 무기 아이콘 표시)를 표시한다.
>     - 플레이어가 확인 버튼을 누르면 선택된 슬롯을 해제하고, 무기의 GA와 오브젝트를 제거한다.
>     - 새 무기에 대한 장착 프로세스를 진행한다. (무기 장착 상세 규칙 참조)
>     - 장착 프로세스가 완료되면 UI를 닫고, 게임 일시정지 상태를 해제한다.
>
> - **예외 처리**
>     - 교체 UI에서 아무것도 선택 안함
>         - 닫기 버튼 제공하여 유저가 전략적으로 스킵할 수 있도록 유도.
>     - 교체 중 게임 강제 종료
>         - 기존 무기 유지(교체 취소)
>

### 상세 규칙

- 상단
    - 상황 표시(LEVEL UP) - 레벨업 이벤트 발생 알림
    - 행동유도 - 플레이어 선택 요구

- 중단
    - 무기카드 3개 표시 및 상세 항목
        - 아이콘(무기 이미지)
        - 무기 이름(최대 20자 이내)
        - 레벨 표시(NEW or LV2 or LV3)
        - 무기 설명
        - 진화가능여부(RedDot)
    - 카드 상태별 표시 규칙
        - 신규무기(미보유) - 테두리 흰색, NEW표시, 기본 텍스트 색상
        - 보유무기(강화가능) - 테두리 녹색, Lv1→Lv2 / Lv2→Lv3 표시, 녹색 텍스트 색상
        - 보유무기(최대레벨) - 테두리 흰색, Lv3(MAX)표시, 회색 텍스트 색상
        - 진화가능무기 - 테두리 무지개색, 레드닷 뱃지 + "진화 가능!" 텍스트, 강조 UI애니메이션, 금색 텍스트 색상
- 카드 하단
    - 선택/확인 버튼
        - 기본 - "선택" 텍스트, 클릭 시 해당 무기로 최종 선택(체크 아이콘 표시)
        - 마우스 호버 - 버튼 확대 애니메이션 + 하이라이트
        - 클릭 - 체크 아이콘 표시 후 확인버튼 활성화. 확인버튼 클릭시 해당 무기로 장착 프로세스 진행

## 무기 교체 UI

- 슬롯이 모두 차있는 상태에서 무기 선택이 진행된 경우
- 레벨업 UI가 교체 UI로 바로 전환.

### 화면 구성

- 상단
    - 상황 표시(LEVEL UP) - 무기 교체 이벤트 발생 알림
    - 행동유도 - 플레이어 선택 요구
- 중단
    - 슬롯 3개 표시 및 상세 항목
        - 아이콘(무기 이미지)
        - 무기 이름(최대 20자 이내)
        - 현재 무기 레벨 표시(LV1 or LV2 or LV3)
        - 무기 설명
        - 진화무기 여부(뱃지)
    - 슬롯 상태별 표시 규칙
        - Lv1 무기 - 테두리 흰색, 기본 텍스트 색상
        - Lv2 무기- 테두리 녹색, 녹색 텍스트 색상
        - Lv3 무기 - 테두리 금색, 금색 텍스트 색상
        - 진화 무기 - 테두리 무지개색, 레드닷 뱃지, 테두리 강조 애니메이션, 금색 텍스트 색상
- 카드 하단
    - 교체 확인 버튼
        - 기본 - "교체 확인" 텍스트, 클릭 시 해당 무기로 최종 선택
        - 마우스 호버 - 버튼 확대 애니메이션 + 하이라이트
        - 클릭 - 해당 무기 슬롯 해제 및 신규 무기 장착 프로세스 진행.
