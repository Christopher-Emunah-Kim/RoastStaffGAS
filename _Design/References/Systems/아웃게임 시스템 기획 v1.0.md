# 💡 아웃게임 시스템 상세 기획서

## 핵심 역할

>
>
>
>
> - 아웃게임 시스템은 OUTGAME 레벨 내에서 로비 · 캐릭터 선택 · 스테이지 선택 · 설정 메뉴를 통합 관리하는 시스템이다.
> - **RSOutGamePlayerController**가 해당 레벨의 유일한 UI 요청자이며, 모든 UI 오픈/클로즈는 UIManagerSubsystem(UMS)을 통해서만 처리한다.
> - 이하 문서에서 `RSOutGamePlayerController`를 **OGPC**로 약어 사용.
>
> **핵심 책임**
>
> - 아웃게임 레벨 진입 시 OUTGAME(PERSISTENT) + LOBBY(PAGE) 위젯 표시
> - 버튼 핸들러를 통해 PAGE 전환 (캐릭터 선택, 스테이지 선택)
> - 캐릭터 선택 완료 시 RuntimeDataSubsystem에 선택 결과 반영
> - 스테이지 선택 완료 시 저장 + 다음 레벨 전환
> - 입력 모드: SetInputMode(FInputModeUIOnly). 아웃게임은 항상 UI 전용 입력.
>

---

## 💡 다른 시스템과의 관계

| 연관 시스템 | 관계 방향 | 설명 |
| --- | --- | --- |
| UIManagerSubsystem | OGPC → UMS | UI 오픈/클로즈/페이지 전환 모두 UMS를 통해 처리. |
| RuntimeDataSubsystem | OGPC → RDS | 캐릭터 선택 완료 시 SetSelectedCharacter(CharID) 호출. |
| SaveGameSubsystem | OGPC → SGS | 스테이지 선택 완료(게임 시작 확정) 시 저장 요청. |
| GameInstance | OGPC → GI | 스테이지 선택 완료 시 GI::OpenNextStage() 호출로 레벨 전환. |
| GameDataSubsystem | 위젯 → GDS | RSCharacterSelectWidget, RSStageSelectWidget이 GDS에서 목록 데이터 조회. |
| StageManagerSubsystem | 위젯 → StageManager | RSStageSelectWidget이 스테이지 목록 조회. |

## 💡 기능 명세 및 상세 규칙

### RSOutGameGameMode 초기화

>
>
>
>
> - OUTGAME 레벨 진입 시 RSOutGameGameMode::BeginPlay()에서 아래 순서로 초기화한다.
>     1. OGPC 취득
>     2. UMS::OpenUIByID(EUIID::OUTGAME) — PERSISTENT 프레임 표시
>     3. UMS::SwitchPageUI(EUIID::LOBBY) — 메인 로비 PAGE 표시
>

### RSOutGamePlayerController 역할

>
>
>
>
> - **입력 모드**: BeginPlay 시 SetInputMode(FInputModeUIOnly) + SetShowMouseCursor(true) 고정.
> - OUTGAME 레벨에서는 캐릭터 이동 입력이 없으므로 게임 입력 바인딩 불필요.
>
> **버튼 핸들러 (위젯 델리게이트로부터 수신):**
>
> | 핸들러 | 트리거 | 처리 |
> | --- | --- | --- |
> | `OnCharacterSelectClicked()` | 로비 위젯의 캐릭터 선택 버튼 | UMS::SwitchPageUI(EUIID::CHAR_SELECT) |
> | `OnStageSelectClicked()` | 로비 위젯의 스테이지 선택 버튼 | UMS::SwitchPageUI(EUIID::STAGE_SELECT) |
> | `OnSettingClicked()` | 로비 위젯의 설정 버튼 | UMS::OpenUIByID(EUIID::SETTING) |
> | `OnCharacterSelected(FName CharID)` | 캐릭터 선택 위젯의 선택 완료 델리게이트 | RDS::SetSelectedCharacter(CharID) → UMS::BackPage() |
> | `OnStageSelected(FName StageID)` | 스테이지 선택 위젯의 선택 완료 델리게이트 | SGS 저장 → GI::OpenNextStage(StageID) |
> | `OnBackClicked()` | 각 PAGE의 뒤로 가기 버튼 | UMS::BackPage() |
>

### UIHistory 흐름

>
>
>
>
> ```
> [LOBBY] (기본 PAGE)
>   → 캐릭터 선택 버튼 → SwitchPageUI(CHAR_SELECT)
>       → 선택 완료 또는 Back → BackPage() → [LOBBY] 복귀
>   → 스테이지 선택 버튼 → SwitchPageUI(STAGE_SELECT)
>       → 선택 완료 → OpenNextStage (레벨 전환)
>       → Back → BackPage() → [LOBBY] 복귀
>   → 설정 버튼 → OpenUIByID(SETTING) [POPUP]
>       → 닫기 → CloseUIByID(SETTING)
> ```
>

## 💡 위젯 구조

| 위젯 | EUIID | 레이어 | 설명 |
| --- | --- | --- | --- |
| RSOutGameWidget | OUTGAME | PERSISTENT | 아웃게임 공통 오버레이 프레임 |
| RSLobbyWidget | LOBBY | PAGE | 메인 로비. 버튼 3개(캐릭터/스테이지/설정) |
| RSCharacterSelectWidget | CHAR_SELECT | PAGE | 캐릭터 목록 표시 및 선택 |
| RSStageSelectWidget | STAGE_SELECT | PAGE | 스테이지 목록 표시 및 선택 |
| RSSettingWidget | SETTING | POPUP | 볼륨 등 설정 조작. 변경 즉시 SGS 저장. |

### RSCharacterSelectWidget

>
>
>
>
> - GDS::GetAllCharacterStaticData()로 캐릭터 목록을 조회하여 카드 형태로 표시한다.
> - RDS::UnlockedCharacterIDs를 기준으로 해금/잠금 상태를 구분한다.
> - 캐릭터 선택 시 `OnCharacterSelectedDel(FName CharID)`를 Broadcast → OGPC가 수신.
>

### RSStageSelectWidget

>
>
>
>
> - StageManagerSubsystem에서 스테이지 목록을 조회한다.
> - GDS::GetCharacterStaticData(StageID)로 스테이지 세부 정보(제한 시간, 보스 여부 등)를 표시한다.
> - 스테이지 선택 시 `OnStageSelectedDel(FName StageID)`를 Broadcast → OGPC가 수신.
>

## 💡 예외처리

| 상황 | 처리 |
| --- | --- |
| RDS에 캐릭터 미선택 상태에서 스테이지 선택 완료 시도 | 경고 로그 + 스테이지 진입 차단. 캐릭터 선택 페이지로 유도. |
| SGS 저장 실패 | 경고 로그 출력. 저장 실패해도 레벨 전환은 진행(다음 진입 시 재저장). |
| BackPage() 호출 시 UIHistory가 비어있는 경우 | LOBBY로 강제 전환. |
