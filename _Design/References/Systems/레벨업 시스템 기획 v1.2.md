# 💡 레벨업 시스템 상세 기획서

## 핵심 역할

> 
> 
> 
> 
> - 레벨업 시스템은 몬스터 처치를 통해 획득한 경험치를 누적하고, 
> 조건 달성 시 레벨업 이벤트를 발생시켜 플레이어에게 무기 선택의 기회를 제공하는 시스템이다.
> - 인게임 로그라이크 성장 사이클의 핵심 축을 담당한다.
> 
> ### **핵심 책임**
> 
> - 몬스터 처치 시 경험치를 계산하여 PlayerState에 누적한다.
> - 누적 경험치가 레벨업 기준치에 도달하면 레벨업 이벤트를 발생시킨다.
> - 레벨업 시 전투를 일시정지하고, 무기 테이블에서 무기 3종을 랜덤 선택하여 UI에 표시한다.
> - 표시할 무기의 진화 가능 여부를 판단하여 UI에 전달한다.
> - 플레이어의 무기 선택이 완료되면 무기 시스템에 장착을 위임하고 전투를 재개한다.
> - 슬롯이 모두 찬 경우 교체 UI로 전환하는 흐름을 관리한다.
> 

## 다른 시스템과 관계

| 연관 시스템 | 관계 방향 | 설명 |
| --- | --- | --- |
| 전투 시스템 | 전투 → 레벨업 | 몬스터 처치 이벤트 발생 시 처치 정보를 스테이지 시스템에 전달한다. |
| 무기 시스템 | 레벨업 → 무기 | 플레이어가 무기를 선택하면 장착 프로세스 실행을 무기 시스템에 위임한다. |
| 플레이어 조작 시스템 | 레벨업 ↔ 조작 | 레벨업 UI 진입 시 전투 일시정지 및 입력 전환을 요청한다. |
| 스테이지 시스템 | 레벨업 ↔ 스테이지 | 스테이지 시스템이 적ID를 레벨업 시스템에 전달한다. 
레벨업 시스템은 전달받은 ID로 GDS를 조회하여 EXP를 PlayerState에 누적한다.
레벨업 UI 진입·종료 시 게임 시간 정지/재개를 요청한다. |

# 💡 기능 명세 및 상세규칙

| 기능 구분 | 상세 기능 |
| --- | --- |
| 경험치 계산 및 누적 | 몬스터 처치 시 적의 전리품 정보(경험치)를 계산하여 PlayerState에 누적한다. |
| 레벨업 달성 판정 | 누적 경험치가 기준치에 도달했는지 판단하고 레벨업 이벤트를 발생시킨다. |
| 무기 후보 선정 | 무기 테이블에서 3종을 랜덤 선택한다. 중복 및 재뽑기 규칙을 적용한다. |
| 진화 가능 여부 판단 | 후보 무기와 현재 보유 무기를 조합 테이블에서 대조하여 진화 가능 여부를 판단한다. |
| 레벨업 UI 표시 | 전투를 일시정지하고 선정된 무기 3종의 정보를 UI에 표시한다. |
| 교체 UI 전환 | 무기 선택 후 슬롯이 모두 찬 경우 교체 UI로 전환한다. |

### 경험치 계산 및 누적 상세 규칙

> 
> 
> 
> 
> - **경험치 계산 규칙**
>     - 몬스터가 처치되면 스테이지 시스템에서 전달받은 해당 몬스터의 DropExp 값을 PlayerState의 현재 누적 경험치에 가산한다.
>     - 경험치 획득 시마다 레벨업 달성 여부를 즉시 판정한다.
>         - 이후 경험치 보너스(특성 등)가 추가되는 경우, DropExp에 보너스 배율을 곱한 값을 누적한다. 보너스 배율은 캐릭터의 GE로 관리한다.
>     
> - **레벨별 필요 경험치 규칙**
>     - 레벨별 필요 경험치는 DT_CurveTable의 EXP 커브를 참조한다.
>     - 레벨업 후 잉여 경험치는 다음 레벨의 누적 경험치에 이월된다.
>         - 예 ) 레벨업 기준치가 100인 상태에서 110 경험치 획득 시, 레벨업 후 10이 이월된다.
>     - 최대 레벨 도달 시 경험치를 더 이상 누적하지 않는다.
> 

### 레벨업 달성 판정 상세 규칙

> 
> 
> 
> 
> - **레벨업 판정 프로세스**
>     - 경험치가 가산될 때마다 현재 누적 경험치와 현재 레벨의 필요 경험치를 비교한다.
>     - (누적 경험치 >= 필요 경험치)인 경우 레벨업 이벤트를 발생시킨다.
>     - 레벨을 1 증가시키고, 잉여 경험치를 다음 레벨로 이월한다.
>     - 레벨업 이벤트 발생 시 아래 항목을 순서대로 처리한다.
>         - 1. 스테이지 시스템에 게임 시간 정지를 요청한다.(TimeScale = 0)
>         - 2. 플레이어 조작 시스템에 전투 입력 차단을 요청한다.
>         - 3. 무기 후보 선정 프로세스를 실행한다. ([무기 후보 선정 상세 규칙](https://www.notion.so/3111ba272aac809798a1eb7d5b97f84a?pvs=21)  참조)
>         - 4. 선정된 무기 정보를 레벨업 UI에 전달하고 표시한다.
>     - 레벨업 이벤트는 경험치 가산 직후 한 번만 발생한다.
> 
> - 예외처리
>     - 연속 레벨업 발생시(이월 경험치로 즉시 레벨업 달성 가능할시
>         - 현재 UI가 닫힌 후 게임 시간 재개 없이 즉시 다음 레벨업 이벤트를 발생시킨다.
> 

### 무기 후보 선정 상세 규칙

> 
> 
> 
> 
> - **무기 3종 랜덤 선정 프로세스**
>     - DT_Weapon에서 Lv1 무기 ID 목록을 가져온다.
>     - 목록에서 무기 3종을 랜덤으로 선택한다.
>     - 중복 방지 규칙을 적용한다.
>         - 동일한 무기 ID가 중복으로 선택된 경우 재뽑기한다.
>         - 재뽑기는 최대 10회까지 시도하며, 10회 초과 시 중복을 허용한다.
>         - 선정된 3종에 대해 진화 가능 여부 판단을 실행한다. 
>         ([진화 가능 여부 판단 상세 규칙](https://www.notion.so/3111ba272aac803bbb9be233eabf36b7?pvs=21)  참조)
>     - 선정 결과(무기 ID 3종 + 진화 가능 여부)를 레벨업 UI에 전달한다.
> 
> - **선정된 무기 카드 표시 정보**
>     
>     
>     | **항목** | **내용** | **비고** |
>     | --- | --- | --- |
>     | 무기 아이콘 | DT_WeaponResources의 IconPath 참조 |  |
>     | 레벨 상태 | 보유 여부 및 강화 단계에 따라 표시 문구 결정 | NEW / Lv1→Lv2 
>     / Lv2→Lv3 / Lv3(MAX) |
>     | 진화 가능 여부 | 진화 가능 시 RedDot 뱃지 + "진화 가능!" 텍스트 | 진화 불가 시 미표시 |
>     | 무기 이름 | DT_String 참조 | 최대 20자 |
>     | 무기 설명 | DT_String 참조 |  |
> - 예외처리
>     - 무기 후보 선정 중 유효 무기가 3종 미만인 경우
>         - 가능한 수량만 표시한다. 최소 1종 이상일땐 UI를 표시한다.
> 

### 진화 가능 여부 판단 상세 규칙

> 
> 
> 
> 
> - 레벨업 UI에 표시할 무기 3종이 선정된 후, 각 후보 무기에 대해 진화 가능 여부를 판단한다.
> 
> - **진화 가능 여부 판단 프로세스**
>     - 후보 무기의 BaseType과 현재 보유 무기들의 BaseType을 DT_Combination에서 대조한다.
>     - 조합 조건이 존재하는 경우, 현재 보유 무기의 레벨이 RequiredLevel 이상인지 확인한다.
>     - 두 조건을 모두 만족하는 경우 해당 후보 무기를 "진화 가능" 상태로 마킹한다.
>     - 진화 가능 여부는 UI 표시 목적으로만 사용한다.
>         - 실제 진화 처리는 무기 시스템이 담당한다.
>     - 진화 가능 여부 판단은 UI 표시 시점에 1회만 수행한다.
> 

### 레벨업 UI 위젯 상세 규칙

> 
> 
> 
> 
> - **UI 진입 시 프로세스**
>     - 게임 시간이 정지된 상태에서 레벨업 UI를 표시한다.
>     - UI 배경에 반투명 어두움 오버레이를 적용하여 전투 화면을 가린다.
>     - 무기 카드 3개를 등장 애니메이션과 함께 표시한다.
>     
> - **플레이어 마우스 입력 처리 프로세스**
>     - 플레이어가 무기 카드 중 하나를 선택하면 해당 카드에 체크 표시와 하이라이트를 추가한다.
>     - 선택된 무기의 강화/진화/신규 장착 상태에 따라 카드에 미리보기 텍스트를 표시한다.
>         - 신규 장착: "새 슬롯에 장착됩니다."
>         - 강화: "현재 Lv1 → Lv2로 강화됩니다."
>         - 진화: "진화 무기로 교체됩니다."
>         - 슬롯 가득참: "슬롯이 가득 찼습니다. 교체할 무기를 선택해주세요."
>     - 플레이어가 확인 버튼을 누르면 장착 프로세스를 무기 시스템에 위임한다.
>     ( [무기 장착 상세 규칙](https://www.notion.so/30e1ba272aac80cc9f56c3195fb4bd2b?pvs=21) 참조)
>     
> - **스킵 처리**
>     - 플레이어가 닫기(X) 버튼을 누르면 무기 선택을 진행하지 않고 UI를 닫는다.
>     - UI가 닫히면 게임 시간 정지를 해제하고 전투를 재개한다.
>     - 스킵 후 GA 활성화 상태를 재확인하여 슬롯 기준 자동공격이 정상 동작하는지 검증한다.
> 
> - 예외처리
>     - UI 진입중 게임 강제 종료 시
>         - 레벨업 이벤트 상태를 저장한다. 재접속 시 레벨업 UI를 재표시한다.
> 

### 레벨업 UI → 교체 UI 전환 상세 규칙

> 
> 
> 
> 
> - 무기 시스템으로부터 "슬롯이 모두 찼으며 진화/강화 조건도 성립하지 않는다"는 결과를 받은 경우, 레벨업 UI에서 교체 UI로 즉시 전환한다.
> 
> - **전환 프로세스**
>     - 레벨업 UI에서 무기 선택 후 확인 버튼을 누르면 무기 시스템이 장착 가능 여부를 판단한다.
>     - 무기 시스템으로부터 교체 필요 신호를 수신하면 레벨업 UI를 닫고 교체 UI로 전환한다.
>     - 교체 UI에는 현재 장착된 슬롯 3개의 무기 정보와 신규 무기 정보를 표시한다.
>     - 게임 시간 정지 상태는 교체 UI에서도 유지된다.
>     - 교체 UI에서 플레이어가 슬롯을 선택하면 해당 슬롯 해제 후 신규 무기 장착을 무기 시스템에 위임한다.
>     ( [무기 장착 상세 규칙](https://www.notion.so/30e1ba272aac80cc9f56c3195fb4bd2b?pvs=21) 참조)
>     - 교체 UI에는 닫기 버튼을 제공하여 플레이어가 전략적으로 교체를 취소할 수 있도록 한다.
> 
> - 예외처리
>     - 교체UI진입 중 게임 강제 종료
>         - 교체를 취소하고 기존 무기를 유지한 상태를 저장한다.
>

## 런타임 사용 데이터

- 레벨업 시스템이 매프레임 관리해야하는 데이터 목록이다. 아래 데이터는 저장되지않고, 게임 진행중에만 유지된다.
- 단, 레벨업 이벤트 진행 중 강제 종료 시에는 예외적으로 트랜잭션 상태를 저장한다.

| **데이터 항목** | **타입** | **설명** |
| --- | --- | --- |
| 현재 레벨 | INT | PlayerState에 저장. 레벨업 시마다 1 증가. |
| 현재 누적 경험치 | INT | PlayerState에 저장. 레벨업 시 잉여분만 유지. |
| 현재 레벨 필요 경험치 | INT | DT_CurveTable EXP 커브에서 현재 레벨 기준으로 조회. |
| 레벨업 이벤트 진행 여부 | BOOL | 레벨업 UI가 열려있는 동안 true. 중복 이벤트 방지용. |
| 무기 후보 목록 | ARRAY<STRING> | 현재 레벨업 UI에 표시 중인 무기 ID 3종. |
| 진화 가능 여부 목록 | ARRAY<BOOL> | 후보 무기 3종 각각의 진화 가능 여부. |

## **DT_CurveTable (EXP 커브) 스키마**

- 레벨별 필요 경험치는 DT_CurveTable에서 관리한다. 
수치 밸런싱이 필요한 경우 이 테이블만 수정하여 적용한다.

| **컬럼명** | **타입** | **제약** | **설명** |
| --- | --- | --- | --- |
| Level | INT | PK, NOT NULL | 캐릭터 레벨 |
| RequiredEXP | INT | NOT NULL | 해당 레벨 달성에 필요한 누적 경험치 |
| MaxHP | FLOAT | NOT NULL | 해당 레벨에서의 최대 HP |
| ATK | FLOAT | NOT NULL | 해당 레벨에서의 공격력 기본값. |

# 💡 UI/UX 상세

## **레벨업 무기 선택 UI**

### **화면 구성**

| **영역** | **위치** | **표시 내용** |
| --- | --- | --- |
| 상단 | UI 상단 | "LEVEL UP!" 타이틀 + "새로운 무기를 선택하세요" 행동 유도 텍스트 
+ 우상단 닫기(X) 버튼 |
| 중단 | UI 중앙 | 무기 카드 3개 (아이콘, 이름, 레벨 상태, 설명, 진화 가능 뱃지) |
| 카드 하단 | 각 카드 아래 | [선택] 버튼 |
| 하단 | UI 하단 | [확인] 버튼 (카드 선택 전 비활성, 선택 후 활성) |

### **카드 상태별 표시**

| **상태** | **테두리** | **레벨 표시** | **텍스트 색상** |
| --- | --- | --- | --- |
| 신규 무기 (미보유) | 흰색 | NEW | 기본 |
| 보유 무기 (강화 가능) | 녹색 | Lv1→Lv2 / Lv2→Lv3 | 녹색 |
| 보유 무기 (최대 레벨) | 흰색 | Lv3 (MAX) | 회색 |
| 진화 가능 무기 | 무지개색 | 현재 레벨 표시 유지 | 금색 |

### **UX 흐름**

- UI 진입 시 카드 3개가 등장 애니메이션과 함께 표시된다. 배경은 반투명 오버레이 처리된다.
- 카드에 마우스를 올리면 카드가 1.05배 확대되고 상세 툴팁이 표시된다.
- 카드를 클릭하면 선택 SFX가 재생되고 카드 테두리가 발광하며 [선택] 버튼에 체크 아이콘이 표시된다.
- [확인] 버튼이 활성화(회색 → 녹색)되어 클릭 가능 상태가 된다.
- [확인] 버튼을 누르면 무기 장착 프로세스를 무기 시스템에 위임하고 UI 제거 애니메이션을 재생한다.
- [X] 버튼을 누르면 선택을 진행하지 않고 UI를 닫은 뒤 전투를 재개한다.

## **무기 교체 UI**

- 슬롯이 모두 차있는 상태에서 진화·강화 조건도 성립하지 않을 때 레벨업 UI에서 즉시 전환된다.

### **화면 구성**

| **영역** | **위치** | **표시 내용** |
| --- | --- | --- |
| 상단 | 모달 상단 | "어떤 무기를 교체하시겠습니까?" 타이틀 + 행동 유도 텍스트 |
| 중단 | 모달 중앙 | 현재 장착된 슬롯 3개의 무기 카드 
(아이콘, 이름, 현재 레벨, 설명, 진화 무기 여부 뱃지) |
| 카드 하단 | 각 카드 아래 | [교체 확인] 버튼 |
| 하단 | 모달 하단 | 신규 장착 예정 무기 정보 표시 |

### **슬롯 상태별 표시 규칙**

| **상태** | **테두리** | **텍스트 색상** |
| --- | --- | --- |
| Lv1 무기 장착 시 | 흰색 | 기본 |
| Lv2 무기 장착 시 | 녹색 | 녹색 |
| Lv3 무기 장착 시 | 금색 | 금색 |
| 진화 무기 장착 시 | 무지개색 + 강조 애니메이션 | 금색 |

### **UX 흐름**

- 레벨업 UI가 닫히며 교체 UI로 전환된다. 게임 시간 정지는 유지된다.
- 슬롯 카드에 마우스를 올리면 선택 시 어떤 무기로 교체되는지 미리보기를 표시한다.
- [교체 확인] 버튼을 누르면 해당 슬롯을 해제하고 신규 무기 장착을 무기 시스템에 위임한다.
- 장착이 완료되면 UI를 닫고 게임 시간 정지를 해제하여 전투를 재개한다.
- [X] 버튼 또는 닫기를 누르면 교체를 취소하고 전투를 재개한다.
