# 게임 시스템 개선안 v2.0
> 작성일: 2026-04-17
> 상태: 확정
> 작성자: 시니 + KARVIS
>
> **대체 범위**: v1.0 전체를 이 문서가 우선한다.
> v1.0에서 유지되는 항목: GAS ExecCalc 데미지 공식, 서브시스템 아키텍처, 데이터 파이프라인 (CSV→DT→Subsystem→GA)

## 변경 배경

포트폴리오 리뷰 피드백: "언리얼의 강점이 보이지 않는다. UI 중심 구성이 유니티스럽다. 전투 연출과 그래픽 우수함이 먼저 보여야 한다."

핵심 방향 전환:
- **삭제**: 재화·해금·스탯트리·커스터마이즈 UI·서브스테이지 구조
- **추가**: 3D 로비 카메라 연출, 분할 스테이지 선택, 피격 반응 시스템, 스킬 6개 액션

## 1. 아웃게임 플로우

### 전체 흐름
```
[로비 레벨] ─ 캐릭터 선택 ─▶ [스테이지 선택 레벨] ─ 스테이지 선택 ─▶ [인게임 레벨]
```

해금 없음 — 모든 캐릭터·스테이지 처음부터 사용 가능.

---

### 1-1. 로비 레벨 (전면 개편)

#### 캐릭터 배치
- 캐릭터 3명이 3D 공간에 각자 고유 위치에 배치
- 각 캐릭터는 개성 있는 대기 애니메이션 재생 중 (캐릭터별 차별화)
  - 예: 앉아있기 / 어딘가에 기대기 / 무기 손질 중

#### 인터랙션 흐름

| 이벤트 | 반응 |
|--------|------|
| 마우스 호버 | 캐릭터 아웃라인 빛남 (CustomDepth + PP 아웃라인) |
| 클릭 (선택) | 기립 + 전투 준비 애니메이션 재생 |
| 선택 확정 | 카메라 블렌드 후 스테이지 선택 레벨로 전환 |

#### 카메라
- **기본 앵글**: 3명 전체를 조망하는 고정 카메라 (언리얼 조명·구도 강조)
- **선택 시**: 해당 캐릭터로 카메라 블렌드 (클로즈업)

#### 우측 UI 패널 (선택 후 표시)
- 캐릭터 닉네임 + 초상화
- 스킬 아이콘 6개 목록 (이름 + 간단 설명)
- 확정 버튼

---

### 1-2. 스테이지 선택 레벨 (전면 개편)

#### 스테이지 구조 변경
| v1.0 | v2.0 |
|------|------|
| STAGE_1 서브 (01-001 ~ 01-004) | 맵 1개 = 보스 스테이지 1개 |
| 스테이지 목록 UI | 화면 분할 선택 |

**맵 매핑**
- MAP_Necropolis → **STAGE_001**
- MAP_Settings → **STAGE_002** (신규 에셋)

#### 화면 분할 방식
- 화면 50/50 좌/우 분할, 각 영역에 해당 맵 프리뷰 표시
- **호버**: 해당 영역 60/40으로 확장 + 강조 연출
- **클릭**: 선택 확정 → 인게임 레벨 로드 트랜지션

#### 표시 정보 (각 영역)
- 스테이지 이름
- 배경 (실제 레벨 스크린샷 또는 스트리밍 프리뷰)
- 보스 에너미 이름 + 아이콘
- 추천 레벨 (선택)

## 3. 스킬 시스템

### 3-1. ESkillActivationType 확장

```cpp
UENUM(BlueprintType)
enum class ESkillActivationType : uint8
{
    InstantAoE,       // 기존 — 캐릭터 위치 즉발 AoE
    SelfBuff,         // 기존 — 자신에게 GE 적용 (이동 포함 가능)
    SpawnPreview,     // 기존 — 프리뷰 배치 후 확정
    ProjectileSpawn,  // 신규 — 투사체 발사 (기존 BaseProjectile 시스템 연동)
    GroundEffect,     // 신규 — 장판 Actor 스폰 (ARS_GroundEffectActor)
};
```

### 3-2. 기존 5종 투사체 → ProjectileSpawn 매핑

| 기존 투사체 타입 | ProjectileSpawn 서브타입 | 사용 스킬 예 |
|---------------|------------------------|------------|
| 직선형 (Linear) | MoveType::Linear | 범가르기, 라이트닝볼텍스 |
| 관통형 (Pierce) | MoveType::Pierce | 아이스애로우, 래피드샷 |
| 궤도형 (Arc) | MoveType::Arc | 애로우해일 |
| 유도형 (Homing) | MoveType::Homing | 콩콩이, 호크샷 |
| 소환형 (Summon) | 기존 GA_SummonBase 활용 | — |

`GA_CharacterSkill::ExecuteProjectileSpawn()` — InitData 조립 후 기존 BaseProjectile 풀 스폰.

## 4. 피격 반응 시스템 (신규)

### 구조
> C++ GAS에서 `PostGameplayEffectExecute`는 AttributeSet 전용 함수.
> `UEnemyAttributeSet`에서 HP 감소 감지 후 `AEnemyBaseCharacter::ApplyHitReact()` 위임.

```
UEnemyAttributeSet::PostGameplayEffectExecute()
  └─ HP 감소 감지 → AEnemyBaseCharacter::ApplyHitReact(ImpactDir) 위임

AEnemyBaseCharacter::ApplyHitReact(FVector ImpactDir)
  ├─ LaunchCharacter(ImpactDir * KnockbackForce)
  ├─ CustomTimeDilation = 0.f → 복원  ← 개별 에너미만 (플레이어 무영향)
  └─ MaterialEmissiveFlash(FlashIntensity, FlashDuration)
      [HitReact 몽타주 — 에셋 확보 시 추가]
```

### 파라미터

| 파라미터 | 타입 | 기본값 | 설명 |
|---------|------|-------|------|
| KnockbackForce | float | 500.f | 넉백 세기 |
| HitstopDuration | float | 0.05f | 히트스탑 시간 |
| HitstopScale | float | 0.05f | TimeDilation 배율 |
| FlashDuration | float | 0.1f | 이미시브 플래시 시간 |
| FlashIntensity | float | 5.f | 이미시브 배율 |

### MaterialEmissiveFlash 구현 방식
- `GetMesh()->GetMaterials()` 순회 → MID(MaterialInstanceDynamic) 생성
- `SetScalarParameterValue("EmissiveIntensity", FlashIntensity)` 적용
- TimerHandle로 FlashDuration 후 0으로 복원
- 에너미 머티리얼에 `EmissiveIntensity` 파라미터 필요 (에디터 작업)

## 5. ElementTag FX 시스템 (신규)

### 속성 태그 → FX 컬러 매핑

```cpp
// GA_CharacterSkill::SpawnSkillFX() 내 분기
FLinearColor Color = FLinearColor::White;
if      (ElementTag == RSTags::Element_Fire)    Color = {1.f, 0.3f, 0.f, 1.f};   // 주황
else if (ElementTag == RSTags::Element_Ice)     Color = {0.3f, 0.8f, 1.f, 1.f};  // 청백
else if (ElementTag == RSTags::Element_Thunder) Color = {1.f, 1.f, 0.f, 1.f};    // 노랑

if (NiagaraComp)
{
    NiagaraComp->SetVariableLinearColor(TEXT("ElementColor"), Color);
}
```

### 신규 Gameplay Tags (등록 필요)
```
Element.Fire
Element.Ice
Element.Thunder
```

## 6. ARS_GroundEffectActor (신규 공통 클래스)

장판 계열 스킬 공용 Actor (먹물세례·인페르노·애로우해일이 동일 클래스 재사용).

| 멤버 | 타입 | 설명 |
|------|------|------|
| Duration | float | 장판 유지 시간 |
| OverlapGEClass | TSubclassOf\<UGameplayEffect\> | 접촉 시 적용 GE |
| FXClass | TSoftObjectPtr\<UNiagaraSystem\> | 루프 Niagara FX |
| Radius | float | 충돌 반경 |
| bRemoveOnEndOverlap | bool | 이탈 시 GE 제거 여부 |

동작:
- `OnComponentBeginOverlap` → `ApplyGameplayEffect(OverlapGEClass)`
- `OnComponentEndOverlap` → `RemoveActiveGameplayEffect` (bRemoveOnEndOverlap=true 시)
- Duration 만료 → 풀 반환
