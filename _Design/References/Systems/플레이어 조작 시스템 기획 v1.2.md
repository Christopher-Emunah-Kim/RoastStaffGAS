# 💡 플레이어 조작 시스템 상세 기획서

## 핵심 역할

> 
> 
> 
> 
> - 플레이어 조작 시스템은 유저의 입력(마우스/키보드)을 게임 내 캐릭터 동작과 전투 능력으로 연결하는 허브 역할을 수행한다.
> - 이 시스템이 수집한 입력 정보는 무기/스킬/레벨업/스테이지 시스템에 전달되서 실제 게임 동작으로 이어진다.
> 
> - 핵심 책임
>     - 키보드/마우스 입력을 게임 상태에 따라 올바른 동작으로 분기한다.
>     - WASD 이동 입력을 쿼터뷰 카메라 기준의 방향으로 변환하여 캐릭터를 이동시킨다.
>     - 마우스 커서가 가리키는 게임 월드 좌표를 계산하여 에임 정보로 캐싱한다.
>     - 차징 입력 중 스킬 궤적 및 범위를 화면에 미리 표시한다.
>     - 인게임 HUD를 통해 전투상태(HP, 경험치, 무기슬롯, 쿨타임 등)를 플레이어에 전달한다.
> 

## 다른 시스템과 관계

| 스킬 시스템 | 조작 → 스킬 | 차징 완료 시 마우스 에임 좌표를 스킬에 전달해 발동한다. |
| 레벨업 시스템 | 조작 ↔ UI | 레벨업 UI 진입/복귀시 게임 시간 일시정지/재개 전환 및 입력모드 전환을 처리한다. |
| 스테이지 시스템 | 조작 → 스테이지 | 스테이지 나가기, 게임 일시정지 요청 등을 처리한다. |

### 이동 처리 상세 규칙

> 
> 
> 
> 
> - **기본 이동 규칙**
>     - 플레이어는 WASD키로 캐릭터를 이동한다.
>     - 이동 방향은 고정된 쿼터뷰 카메라의 시점을 기준으로 계산된다.
>         - W키 : 카메라 기준 전방(화면 위 대각선 방향)으로 이동
>         - S키 : 카메라 기준 후방(화면 아래 대각선 방향)으로 이동
>         - A/D키 : 카메라 기준 좌/우 방향으로 이동
>     - 대각선 입력은 두 방향의 합산 벡터로 처리하며, 속도는 동일하게 유지된다.
>     - 이동 방향에 따라 캐릭터 에니메이션이 자동으로 전환된다(전/후/좌/우 8방향 블렌딩)
> 
> - **기본 이동 예외처리**
>     - UI 오버레이 활성 중 이동 입력 - 입력을 무시한다. 캐릭터는 정지 상태를 유지한다.
>     - 플레이어 사망 상태에서 이동 입력 - 이동 입력을 차단한다. 캐릭터는 사망 상태를 유지한다.
>     - 빙결 상태 등 이동관련 상태이상에서 이동 입력 - 상태이상이 해제될때까지 이동을 차단한다.
> 

### 마우스 에임 처리 상세 규칙

> 
> 
> 
> 
> - 마우스 에임은 화면위의 마우스 커서 위치를 게임월드의 바닥 좌표로 변환하여 저장하는 시스템이다.
> - 이 좌표(이하 에임 좌표)는 스킬 발동 방향, 궤적 미리보기, 유도형 투사체 초기 타겟 지정에 공통으로 활용된다.
> 
> - **마우스 에임 규칙**
>     - 마우스가 움직이거나 매 프레임마다 에임 좌표를 갱신한다.
>     - 카메라에서 마우스 커서 방향으로 보이지 않는 선(라인트레이스)을 게임 월드 바닥을 향해 발사한다.
>     - 해당 선이 바닥과 만나는 지점의 3D 좌표를 에임 좌표로 저장(캐싱)한다.
> 
> - **에임 좌표 활용 대상**
>     - 액티브 슬롯 스킬 발사
>         - 지정된 에임 좌표 방향으로 스킬을 발동한다.
>     - 곡사형 투사체 궤적 미리보기
>         - 에임 좌표를 목표점으로 발사하여 포물선 궤도를 계산하고 화면에 표시한다.
>     - 폭발형 투사체 범위 미리보기
>         - 에임 좌표를 중심으로 폭발반경을 원형으로 표시한다.
>     - 유도형 투사체 초기 타겟 지정
>         - 에임 좌표 근처 적을 탐색하여 초기 추적 타겟으로 지정한다.
> 
> - 에임 예외처리
>     - 라인트레이스가 바닥과 만나지 않는 경우(맵 외곽 등)에는 직전에 저장된 좌표를 유지한다.
>     - 라인트레이스는 바닥에만 반응하도록 설정한다.
>     - 적/투사체/장애물 등과는 충돌을 무시하여 에임처리에 이상이 없도록 한다.
> 

### 차징 입력 처리 상세 규칙

> 
> 
> 
> 
> - 차징(Charging)은 마우스 버튼을 누르고 있는 동안 스킬의 궤적 또는 범위를 화면에 미리 보여주고, 버튼을 떼는 순간 스킬을 발동하는 입력 방식이다.
> - 차징 입력은 액티브 모드로 전환된 슬롯에서만 동작한다.
> 
> - **차징 입력 프로세스**
>     - 마우스 버튼을 누르면 차징이 시작된다.
>     - 차징 시작과 동시에 HUD 하단에 차징 프로그레스바와 "캐스팅 중..." 텍스트가 표시된다.
>     - 버튼을 누르고 있는 동안 에임 좌표를 지속적으로 갱신하며, 스킬 타입에 따른 미리보기를 표시한다.
>         - 곡사형: 에임 좌표까지의 포물선 궤도를 선으로 표시한다.
>         - 폭발형: 에임 좌표 중심의 폭발 반경을 원형 장판으로 표시한다.
>         - 유도형: 에임 좌표 근처의 적에 Lock-On 마커를 표시한다.
>         - 그 외 : 즉시 발사형이므로 미리보기를 표시하지 않는다.
>     - 마우스 버튼을 떼면 차징이 완료되며, 캐싱된 에임 좌표를 기반으로 스킬을 발동한다.
>     - 스킬 발동과 동시에 미리보기 표시와 프로그레스바를 제거한다.
> 
> - **차징 입력 취소 조건**
>     - 차징 중 플레이어가 사망하면 차징을 즉시 취소하고 스킬을 발동하지 않는다.
>     - 차징 중 레벨업 UI에 진입하면 차징을 즉시 취소한다.
>     - 차징 중 해당 슬롯의 무기가 교체·해제되면 차징을 즉시 취소한다.
>     - 차징이 취소되는 모든 경우에 미리보기 표시와 프로그레스바를 즉시 제거한다.
> 
> - **차징 예외처리**
>     - 액티브 슬롯의 무기가 없는 상태에서 차징 시도
>         - 로그를 출력하고 입력을 무시한다.
>     - 차징 중 빙결 등 상태이상 적용
>         - 차징을 강제 취소하고 스킬을 발동하지 않는다.
>     - 차징 완료 시점에 에임좌표 캐시가 존재하지않음
>         - 가장 마지막에 저장된 에임좌표를 사용하여 스킬을 발동한다.
> 

### 슬롯 액티브 모드 전환 상세 규칙(MVP단계에서는 미구현)

> 
> 
> 
> 
> - 기본적으로 모든 슬롯의 무기는 자동으로 공격한다.
> - 추후 확장 시 Num 1/2/3키로 특정 슬롯을 액티브 모드로 전환하면, 해당 슬롯만 마우스 차징 입력을 받아 플레이어가 직접 발동할 수 있도록 한다.
> 
> - **전환 프로세스**
>     - Num 1/2/3 키를 누르면 해당 슬롯이 액티브 모드로 전환된다.
>     - 이미 액티브 모드인 슬롯의 키를 다시 누르면 액티브 모드가 해제되고 자동공격으로 복귀한다.
>     - 다른 슬롯의 키를 누르면 기존 슬롯은 자동공격으로 복귀하고 새 슬롯이 액티브 모드로 전환된다.
>     - 액티브 모드 슬롯만 차징 입력을 받으며, 나머지 슬롯은 자동공격을 유지한다.
>         
>         
>         | **상태** | **자동공격 슬롯** | **차징 입력 슬롯** |
>         | --- | --- | --- |
>         | 기본 상태 (MVP) | 슬롯 0, 1, 2 전체 | 없음 |
>         | 슬롯 0 액티브 | 슬롯 1, 2 | 슬롯 0 |
>         | 슬롯 1 액티브 | 슬롯 0, 2 | 슬롯 1 |
>         | 슬롯 2 액티브 | 슬롯 0, 1 | 슬롯 2 |
> 

### 입력 상태 전환 상세 규칙

> 
> 
> 
> 
> - 게임 중 UI가 열리는 상황이 발생하면, 전투 입력이 UI 뒤로 새지 않도록 입력 우선순위를 전환한다.
> - UI 입력은 별도의 입력 매핑 없이 위젯이 자체적으로 마우스 클릭을 처리한다.
> 
> - **입력상태 전환 규칙**
>     - UI가 닫히면 즉시 전투 입력 상태로 복귀한다.
>     - UI가 열려있는 동안 눌린 키 입력은 복귀 시 잔류하지 않도록 처리한다.
>     
>     | **게임 상태** | **입력 처리 방식** | **전투 입력 여부** |
>     | --- | --- | --- |
>     | 인게임 전투 중 | 전투 입력 활성화. 
>     마우스는 에임 전용으로 사용된다. | O |
>     | UI 오버레이 활성 
>     (레벨업·교체) | UI가 마우스 입력을 우선 처리한다. 
>     전투 입력(이동 등)은 차단된다. | X |
>     | 일시정지 | 모든 전투 입력이 차단된다. 
>     일시정지 메뉴만 입력을 받는다. | X |

## **무기 슬롯 위젯 상세 규칙**

슬롯은 현재 장착된 무기의 상태에 따라 5가지 표시 상태를 가진다.

| **상태** | **시각적 표현** | **발생 조건** |
| --- | --- | --- |
| 기본 (자동공격 중) | 기본 테두리, 스케일 1.0, 쿨타임 오버레이 표시 | 액티브 모드가 아닌 슬롯 |
| 액티브 모드 | 하이라이트 테두리 발광, 스케일 1.1로 확대 | 해당 슬롯이 액티브 모드로 전환된 경우 |
| 쿨타임 진행 중 | 슬롯 위에 시계방향 어두운 오버레이 
+ 남은 시간(초) 텍스트 | 무기 스킬의 쿨타임이 진행 중인 경우 |
| 슬롯 비어있음 | 잠금 아이콘 표시, 비활성 처리 (클릭 불가) | 해당 슬롯에 무기가 없는 경우 |
| 진화 무기 장착 | 무지개색 테두리 애니메이션 추가 | 장착된 무기가 진화 무기인 경우 |
- 쿨타임 동기화가 실패한 경우 쿨타임을 0으로 초기화하고 슬롯을 정상 표시한다.

## **차징 입력 프로그레스바 위젯 상세 규칙**

| **항목** | **내용** |
| --- | --- |
| 위치 | 하단 중앙 무기 슬롯 바로 위. 슬롯 3개와 동일한 가로 폭으로 표시. |
| 표시 조건 | 차징이 시작될 때만 표시된다. 평소에는 숨겨져 있다. |
| 표시 내용 | 채워지는 프로그레스바 + "캐스팅 중..." 텍스트 |
| 색상 변화 | 0% = 흰색 → 80% = 노란색 → 100% 도달 시 녹색 플래시 후 스킬 발동 |
| 취소 시 처리 | 차징이 취소되면 프로그레스바를 즉시 숨긴다. 채워진 수치는 초기화한다. |
- 차징 중 강제 화면 전환(사망 등)이 발생한 경우 프로그레스바를 즉시 숨기고 차징 상태를 초기화한다.
